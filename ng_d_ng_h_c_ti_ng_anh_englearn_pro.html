Hướng Dẫn Đưa Web Lên GitHub Pages

Các bước từng bước chi tiết giúp bạn xuất bản trang web này hoàn toàn miễn phí!

1

Tạo Tài Khoản & Repository trên GitHub

Truy cập GitHub.com và đăng ký tài khoản miễn phí. Sau khi đăng nhập, bấm vào dấu "+" ở góc phải trên cùng chọn "New repository".

Đặt tên Repository (VD: hoc-tieng-anh-app) và chọn chế độ Public.
2

Tải Tệp Mã Nguồn Up Lên

Lưu toàn bộ mã nguồn của trang web này thành 1 file duy nhất với tên index.html trên máy tính của bạn.

Trong giao diện Repository mới tạo trên GitHub, chọn "uploading an existing file", kéo tệp index.html vào và bấm "Commit changes".
3

Kích Hoạt GitHub Pages

Vào mục Settings của Repository -> chọn mục Pages ở cột menu bên trái.

Tại mục Branch, chọn nhánh main (hoặc master) và chọn thư mục /(root), sau đó nhấn Save.
4

Hoàn Thành & Truy Cập Web

Sau khoảng 1 - 2 phút, GitHub sẽ hoàn tất việc xuất bản web.

Đường link web của bạn sẽ có dạng:
https://<ten-user-github>.github.io/<ten-repo>/
